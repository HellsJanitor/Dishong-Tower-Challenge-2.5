	-REQUIRES EAC to be turned off.
	-This must be installed on the client to work.
	-All 13 languages supported
	-EnhancedPatch-ClientSideNoEAC is SAFE to install on new or existing games.
	-EnhancedPatch-ClientSideNoEAC is SAFE to remove from an existing game.

4.  FEATURES

FIRST, AGF is NOT the author of the .dll component of this file, only the display on the HUD.
	You can find more information about the .dll here: https://github.com/s7092910/PlayerStatController


	-Requires HUDPlus-1Main installed, EAC off, and this Patch installed client side.
	-Food and Water displays both amount and percentages.
	-XP to Next Level and Lootstage is displayed.
	-Can see current capacity of your inventory.
